# Assistant d'étude IA — Pack Markdown

Ce pack propose une base de documentation pour créer un assistant qui analyse les cours, prépare des références, génère des exercices et corrige les réponses.

## Fichiers
- `01_context_engineering.md` : structurer le contexte fourni au modèle.
- `02_harness_engineering.md` : organiser le fonctionnement et les contrôles du système.
- `03_prompt_assistant_etudes.md` : prompt prêt à utiliser avec un cours.
- `04_workflow_etude.md` : procédure recommandée pour chaque matière.
- `05_evaluation_qualite.md` : tests de qualité des résumés, références et exercices.

## Démarrage rapide
1. Ouvrez ChatGPT et créez une conversation dédiée à une matière.
2. Joignez le PDF, le PowerPoint ou les notes du cours.
3. Copiez le contenu de `03_prompt_assistant_etudes.md`.
4. Demandez d'abord l'analyse du cours, puis les références et les exercices.
5. Vérifiez les références externes et les solutions avant de les utiliser.

Pour un usage personnel, commencez sans coder. Pour une application multi-matières, ajoutez progressivement une recherche documentaire (RAG), une gestion des fichiers et des tests automatisés.
